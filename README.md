
# Практическая работа №3

Автоматизация резервного копирования и проверка восстановления данных

ФИО: Вавилова Кристина Дмитриевна  
Вариант: 8

## Цель работы

Разработать программу резервного копирования
данных компании с проверкой целостности,
ротацией архивов и восстановлением файлов.

## Описание проекта

В проекте моделируется работа IT-компании
с тремя отделами:

- dev — разработка
- qa — тестирование
- docs — документация

В каждом отделе создаётся 6 CSV-файлов.
Всего программа обрабатывает 18 файлов.

## Файлы проекта

make_test_data.py — создание тестовых данных.

backup.py — создание резервных копий,
проверка целостности SHA-256,
ротация архивов и восстановление данных.

rpo_rto.md — расчёт показателей RPO и RTO.

## Запуск программы

Создание тестовых данных:

python make_test_data.py

Создание и проверка резервной копии:

python backup.py

## Пример вывода

[OK] Создан backup_20261110_211429.tar.gz,
файлов: 18, размер: 14.4 КБ

[ROTATE] Удалена старая копия

[OK] Восстановление проверено:
18 файлов совпадают

## Восстановление данных

Для восстановления последней копии:

python -c "from pathlib import Path; from backup import restore; restore(sorted(Path('backups').glob('backup_*.tar.gz'))[-1])"

Пример результата:

[OK] Данные восстановлены: 18 файлов
Время восстановления: 0.0788 сек.

## Результаты

Программа успешно создаёт архивы,
проверяет контрольные суммы файлов
и удаляет старые резервные копии.

Для варианта 8 сохраняются
5 последних архивов.

Проверка повреждённого JSON-манифеста
показала изменённый и лишний файл.

При повреждении архива программа
обнаружила несовпадение SHA-256.

После удаления папки dev данные
были восстановлены из резервной копии.

Расчётный RTO: 1 час 14 минут.
